# MARQUES BINGO APP

Mobile-first, real-time multiplayer Bingo. Vite + React + TypeScript, Tailwind, Framer Motion, Firebase Realtime Database (free Spark plan), hosted on Netlify.

- Setup and deploy: [SETUP.md](SETUP.md)
- Security rules: [database.rules.json](database.rules.json)

```bash
npm install
npm run dev        # app
npm run emulators  # local Firebase
npm run dev:emulator  # app against the local emulators
npm test           # unit tests
npm run test:rules # security-rules tests (emulators running)
```
